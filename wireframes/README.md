# طرح رنگی مدرن ۲۰۲۶

پیش‌نمایش رنگی سه صفحه اصلی برای سایت **بازیابی اطلاعات + تعمیر استوریج + گارانتی + آموزش + فروشگاه نرم‌افزار**.

## پالت

| نقش | کد |
|-----|-----|
| پس‌زمینه | `#F3F4F2` |
| سطح | `#FAFBFA` |
| متن | `#14181F` |
| متن فرعی | `#5C6570` |
| بنر | `#0B0F14` |
| متن بنر | `#F4F6F8` |
| برند/تیل | `#0F5C56` |
| اکسنت CTA | `#0F8A6B` |
| فروشگاه | `#1F6B8A` |

## مشاهده

```bash
cd wireframes && python3 -m http.server 8080
```

- فهرست: `http://localhost:8080/`
- صفحه اول: `http://localhost:8080/home.html`
- صفحه شرکتی: `http://localhost:8080/corporate.html`
- فروشگاه: `http://localhost:8080/shop.html`

## نکته

این نسخه برای بررسی رنگ و چیدمان است؛ هنوز بک‌اند و محتوای نهایی نیست.
