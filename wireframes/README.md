# طرح گرافیکی اولیه (وایرفریم)

پیش‌نمایش چیدمان سه صفحه اصلی برای سایت **بازیابی اطلاعات + تعمیر استوریج + گارانتی + آموزش + فروشگاه نرم‌افزار**.

## مشاهده

```bash
cd wireframes && python3 -m http.server 8080
```

سپس:

- فهرست: `http://localhost:8080/`
- صفحه اول: `http://localhost:8080/home.html`
- صفحه شرکتی: `http://localhost:8080/corporate.html`
- فروشگاه: `http://localhost:8080/shop.html`

## نکته

این فایل‌ها وایرفریم بررسی هستند، نه طراحی نهایی و نه بک‌اند.
