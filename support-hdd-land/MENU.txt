سیستم ورود/خروج قبض مشتری برای تعمیرگاه
تأیید لایو: 2026-08-07 با حساب مدیر

نقش‌ها: مدیر | پذیرش | تعمیرکار | حسابدار | کارمند

منوی کارمند (App\Support\NavMenu) — تأیید شده روی لایو:
1) میز کار → /dashboard
   آمار: کارهای باز / آماده تحویل / دریافتی امروز / کم‌موجود
2) پذیرش
   - پذیرش جدید (ثبت قبض) → /receptions/create
   - جستجوی قبض → /receptions/search
   - لیست قبض‌ها → /receptions
   - تحویل گروهی (خروج چند قبض) → /deliveries/group
2b) ارجاع / کارتابل تعمیر → /handoffs
   - تأیید دریافت دستگاه (بله/خیر + سریال)
   - هارد دیسک‌های دست تعمیر
   - بازگشت دستگاه به پذیرش برای تحویل مشتری
2c) اعلان‌ها → /notifications
   - اعلان ارجاع + پیام مشتری به منشی/تعمیرکار/مدیر
3) مشتریان → /customers (+ ایجاد)
4) انبار/قطعات → /parts
5) تعمیرکاران → /technicians
6) کارمندان → /employees
7) وضعیت / پیامک → /sms-statuses
8) حسابداری → /accounting
9) گزارش‌ها
   - عملیات کارگاه → /reports/operations
   - ارجاع / محل دستگاه → /reports/custody
   - صندوق و دریافت‌ها → /reports/payments
   - عملکرد تعمیرکاران → /reports/technicians
   - مشتریان → /reports/customers
   - کالای خرج‌شده → /reports/parts-used
   - پیامک وضعیت → /reports/sms
   - پیام مشتری → /reports/messages
10) تنظیمات → سیستم + پروفایل
    شامل: منوهای پذیرش (نوع پذیرش/خدمات/تعمیر/گارانتی/ظرفیت/برند)،
    انواع ایراد، نحوه آشنایی، فاکتور/چاپ، زرین‌پال، پیامک نیازپرداز

جریان قبض:
  پذیرش جدید → جزئیات قبض (وضعیت/قطعه/پرداخت/چاپ) → تحویل گروهی (خروج)
وضعیت‌های دستگاه:
  پذیرش شده → در حال تعمیر → منتظر قطعه → تعمیر شده / غیرقابل تعمیر → تحویل شده / لغو شده
  (+ پیامک مشتری هنگام تغییر وضعیت)

کارتابل مشتری (/cartable):
- ورود موبایل+SMS (+ remember cookie تا رفرش/PWA بیرون نیندازد)
- میز کار / جستجو / آماده / گزارش / پرداخت زرین‌پال
- پیام به تعمیرگاه (/cartable/messages) درباره قبض
- نمایش محل دستگاه (Custody) و ردیابی ارجاع

Chain of Custody:
  پذیرش → ارجاع به تعمیرکار → تأیید دریافت → دست تعمیر
  → ارجاع بازگشت به پذیرش → تأیید منشی → تحویل مشتری

شماره قبض نمونه: SH-YYMMDD-NNNN

فیکس‌های لایو:
- app.css (+ .hidden تب ورود)
- portal.css / js/app.js / pwa/*
