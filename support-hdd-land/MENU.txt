سرزمین هارد — support.hdd-land.ir
سیستم ورود/خروج قبض مشتری برای تعمیرگاه

نقش‌ها: مدیر | پذیرش | تعمیرکار | حسابدار | کارمند

منوی کارمند (App\Support\NavMenu):
1) میز کار → /dashboard
2) پذیرش
   - پذیرش جدید (ثبت قبض) → /receptions/create
   - جستجوی قبض → /receptions/search
   - لیست قبض‌ها → /receptions
   - تحویل گروهی (خروج چند قبض) → /deliveries/group
3) مشتریان → /customers (+ ایجاد)
4) انبار/قطعات → /parts (+ ایجاد، تنظیم موجودی)
5) تعمیرکاران → /technicians
6) کارمندان → /employees (دسترسی/SMS/ورود)
7) وضعیت / پیامک → /sms-statuses
8) حسابداری → /accounting (+ اسناد، سرفصل، معین، تراز، بدهکاران، سند دستی)
9) گزارش‌ها → عملکرد تعمیرکاران / مشتریان / کالای خرج‌شده
10) تنظیمات → سیستم + پروفایل

کارتابل مشتری (/cartable):
- ورود با موبایل+SMS
- میز کار / جستجو / آماده / گزارش / پرداخت (زرین‌پال)

فیکس‌های اعمال‌شده روی لایو (۷ آگوست ۲۰۲۶):
- بازیابی public/css/app.css + افزودن .hidden برای تب ورود
- افزودن public/css/portal.css
- افزودن public/js/app.js
- افزودن public/pwa/{manifest.json,icon-192.png,icon-512.png}
