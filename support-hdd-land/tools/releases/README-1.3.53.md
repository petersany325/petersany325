# SEO — فقط سایت فروشنده (seller)

موتور SEO در کد اصلی هست ولی با `LicenseStatus::isSellerSite()` قفل شده است.

- روی نصب مشتری (با LICENSE_KEY) تب/منو/robots/sitemap/متا SEO فعال نمی‌شود.
- **هیچ پکیج آپدیت مشتری برای SEO منتشر نشود.**
- نسخه مشتری روی `1.3.52` مانده؛ `1.3.53` SEO-only برای مشتری حذف شد.

برای سایت فروشنده (`support.hdd-land.ir` بدون LICENSE_KEY):
تنظیمات → سئو / گوگل
