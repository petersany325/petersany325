# آپدیت‌های مشتری — بدون SEO

SEO / گوگل **فقط** برای سایت فروشنده (`LICENSE_KEY` خالی) است و نباید در هیچ پکیج آپدیت مشتری بیاید.

قفل کد:
- `App\Support\CustomerReleaseGuard` هنگام ساخت ZIP از تابلو و آپلود دستی، مسیرهای SEO را حذف/رد می‌کند.
- `SeoSettings::available()` روی نصب مشتری همیشه خاموش است.

فایل‌های مجاز مشتری در این پوشه: مثل `hddland-1.3.52.zip` (بدون موتور SEO).

`README-1.3.53.md` فقط یادداشت داخلی است — پکیج `1.3.53` SEO برای مشتری حذف شده و منتشر نشود.
