نصب بدون Terminal (هاست اشتراکی) — مثل ویبولیتین
================================================

1) فایل zip را در مسیر دامنه Extract کنید
   مثال: public_html/dev

2) Document Root را یکی از این دو حالت بگذارید:
   الف) روی خود پوشه پروژه  (پیشنهادی با این بسته — index.php و .htaccess ریشه کار می‌کنند)
   ب) روی پوشه public

3) در مرورگر باز کنید:
   https://دامنه-شما/install.php
   یا اگر Document Root روی public است: https://دامنه-شما/install.php
   یا در غیر این صورت: https://دامنه-شما/public/install.php

4) مراحل ویزارد:
   - پیش‌نیازها
   - سریال لایسنس + دامنه
   - دیتابیس MySQL:
       * پیشنهادی: «ساخت خودکار با cPanel»
         (آدرس سرور cPanel + یوزر/رمز cPanel + نام کوتاه DB/کاربر + رمز MySQL)
         نصب‌کننده خودش Database و User می‌سازد و ALL PRIVILEGES می‌دهد
       * یا دستی: اگر از قبل در cPanel ساخته‌اید، مشخصات کامل را وارد کنید
   - نام تعمیرگاه + مدیر
   - نصب نهایی (migrate + ساخت مدیر)

5) ورود با ایمیل/رمز مدیری که در ویزارد ساختید

نکته‌ها
-------
- نیازی به SSH / Terminal / composer روی هاست مشتری نیست
- برای ساخت خودکار DB، یوزر ورود cPanel لازم است (کاربر عادی MySQL اجازه CREATE DATABASE ندارد)
- داده دمو ساخته نمی‌شود
- هر سریال معمولاً به یک دامنه قفل می‌شود
- بعد از نصب می‌توانید public/install.php را حذف کنید
