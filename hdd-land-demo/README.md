# دموی کامل سرزمین هارد — demo.hdd-land.ir

نسخه تعاملی برای تست مشتری (بدون SMS و پرداخت واقعی).

## ورود دمو
| نقش | موبایل | رمز |
|---|---|---|
| مدیر | 09120000000 | 1234 |
| پذیرش | 09120000002 | 1234 |
| تعمیرکار | 09120000004 | 1234 |
| حسابدار | 09120000007 | 1234 |
| کارآموز | 09120000008 | 1234 |
| مشتری | 09120000001 | کد OTP: 1234 |

## منوهای فعال
میز کار، پذیرش، تحویل گروهی، ارجاع، اعلان‌ها، دفتر روز، تأیید هزینه، مشتریان، انبار، کارمندان، کارآموز، تعمیرکاران، پیامک‌ها، حسابداری، گزارش‌ها، ابزارها (ریست دمو)، تنظیمات، کارتابل مشتری، فروشگاه، شرکتی، نوبت.

## نصب روی هاست
1. محتویات این پوشه را در Document Root ساب‌دامین `demo.hdd-land.ir` آپلود کنید.
2. بهتر است Document Root روی پوشه `public` باشد.
3. در `config.php` مشخصات MySQL دمو را چک کنید (از قبل پر شده).
4. اگر MySQL در دسترس نباشد خودکار از SQLite (`data/demo.sqlite`) استفاده می‌شود.
5. از منوی **ابزارها → ریست کامل داده دمو** می‌توانید داده را به حالت اولیه برگردانید.

## نکته
این دمو برای فروش/تست است و جایگزین کامل Laravel عملیاتی `support.hdd-land.ir` نیست؛ همه منوها را برای نمایش مسیر کار پوشش می‌دهد.
