# بهینه‌سازی منوی موبایل HDD Land / حساب

پچ‌های آماده برای آپلود روی سرور. سورس فروشگاه و حساب در این ریپو نیست؛ cPanel/FTP فعلی هم دسترسی نداد.

## یافته‌ها (ممیزی زنده)

### `hdd-land.ir` (دراور + تب‌بار پایین)
- دراور RTL درست کار می‌کند (اسلاید از راست، backdrop، قفل اسکرول).
- **مشکل اصلی:** تب‌بار پایین (`site-wa-tabbar` / `wa-tabbar`) وقتی منو باز است روی آیتم‌های پایین دراور می‌افتد و لمس را سخت می‌کند.
- z-index تب‌بار (۸۰) نسبت به دراور فروشگاه/وب‌اپ باید پایین‌تر بماند و هنگام باز بودن منو غیرفعال شود.

### `hesab.hdd-land.ir/m/`
- صفحه لاگین موبایل تمیز است؛ تب‌های ورود روی عرض کم شلوغ می‌شوند.
- تب‌بار ۵ستونه داخل اپ بعد از لاگین نیاز به safe-area و فاصله لمسی بهتر دارد.

## فایل‌ها و مسیر آپلود

| فایل پچ | مسیر پیشنهادی روی سرور | بعد از آپلود |
|---------|------------------------|--------------|
| `webapp.mobile-menu-fix.css` | `public_html/css/webapp.css` (append یا جایگزین بخش دراور) | `?v=` را در layout یک واحد بالا ببرید (الان `v=24`) |
| `mega-menu.mobile-fix.css` | `public_html/css/mega-menu.css` (append) | `?v=` → مثلاً `63` |
| `hesab-mobile.menu-fix.css` | `hesab.../assets/css/mobile.css` (append) | `?v=` → مثلاً `2` |

## اعمال

1. بکاپ از CSS فعلی بگیرید.
2. محتوای هر پچ را **به انتهای** فایل CSS مربوطه بچسبانید (یا با merge دستی).
3. نسخهٔ query string را در قالب Blade/PHP بالا ببرید تا کش پاک شود.
4. روی موبایل واقعی یا DevTools (۳۹۰×۸۴۴) منو را باز کنید و اسکرول تا آخرین آیتم را چک کنید.

## تأیید لازم قبل از دیپلوی

این پچ‌ها هنوز روی سرور اعمال نشده‌اند. برای آپلود نیاز است:

- مسیر دقیق Document Root فروشگاه و حساب، یا
- توکن/پسورد معتبر cPanel، یا
- ریپوی سورس فروشگاه.
