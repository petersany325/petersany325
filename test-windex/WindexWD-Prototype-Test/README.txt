مهم: پوشه را دوبار کلیک نکنید. index.html را مستقیم باز نکنید.

1) اجرا (فوری):
   RUN.bat
   یا START-WINDEX-WD.bat

2) اگر خطا داد:
   CHECK.bat

3) ساخت EXE (اختیاری):
   BUILD-EXE.bat  (یک بار — اینترنت لازم است)
   بعد: WindexWD.exe

4) لایسنس:
   Demo unlock (14 days) یا File → License Settings

5) مسیر FW / Backup:
   D:\test windex\FW
   D:\test windex\Backup
