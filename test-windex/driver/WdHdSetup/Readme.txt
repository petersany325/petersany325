- WD Drive PassThrough Driver Installation.doc
  - Documentation on driver installation and hardware requirements

- WdHdSetup.exe
  - Driver Installation for WdHdxxx.sys drivers
  - WdHd*.inf and WdHd*.sys must reside in the same folder as this executable
  - See WdHdSetup.txt for more information

- WdHdGen.inf & WdHdGen.sys
  - Installation file and driver for the 'generic' ICHx based IDE controllers

- WdHdPro.inf & WdHdPro.sys
  - Installation file and driver for the Promise TX based IDE controllers

- WdHdSi.inf & WdHdSi.sys
  - Installation file and driver for the SiliconImage 3124/3132 IDE controllers

- WdHddMsg.exe
  - Tool to filter debugging messages from WdHd*.sys driver
  - See WdHddMsg.txt for more information

- DbgView.exe (Microsoft-SysInternals)
  - Display debugging messages from drivers and tools
  - See sysinternals.com for more information
