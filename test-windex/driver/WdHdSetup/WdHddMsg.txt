WdHddMsg 1.3.2 for Windows XP



DESCRIPTION

This utility uses the library WinDriveRouter to disable or enable the debug
messages output by the WdHd drivers (used by Windex.exe).

Requires the kernel driver to have been already installed and running.



FEATURES

- Selection of the adapter that has the driver installed
- Disable all debug messages
- Enable one, a group, or all debug messages



INSTALLATION

- Copy WdHddMsg.exe to a local directory in the system's hard drive.
- At least one WdHd driver (e.g., WdHdGen.sys, WdHdPro.sys) must have been installed
