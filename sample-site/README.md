# طرح نمونه سایت وکالت — مؤسسه حقوقی آریان

نسخهٔ HTML/CSS نمونه (RTL فارسی) برای بررسی ظاهر قبل از توسعهٔ بک‌اند.

## اجرا

فایل `sample-site/index.html` را در مرورگر باز کنید، یا:

```bash
cd sample-site && python3 -m http.server 8080
```

سپس به `http://localhost:8080` بروید.

## آیا لاراول لازم است؟

**برای طرح نمونه و سایت معرفی ساده: خیر.**

لاراول وقتی مفید است که بخواهید:

- پنل مدیریت محتوا (خدمات، مقالات، تیم)
- ذخیره و مدیریت درخواست‌های مشاوره
- نوبت‌دهی آنلاین
- پنل موکل / ورود کاربر
- وبلاگ حقوقی با مدیریت آسان

پیشنهاد: اول ظاهر را تأیید کنید؛ بعد در صورت نیاز همین طرح را به Blade/Laravel منتقل می‌کنیم.
