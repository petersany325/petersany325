# هم‌گپ — HamGapXBot

ربات چت ناشناس تلگرام روی هاست `dev.hdd-land.com` (پوشه `chatrom`).

## امکانات MVP
- ثبت‌نام: جنسیت / سن / شهر
- منوی گرافیکی (بنر + دکمه)
- چت تصادفی رایگان
- چت با پسر / دختر (۱ سکه)
- رله پیام ناشناس + بعدی / پایان / گزارش
- ۳ سکه هدیه شروع

## مسیرها روی سرور
- وب‌هوک: `/webhook.php?secret=...`
- نصب دیتابیس: `/install.php?key=...` (یک‌بار)
- لندینگ: `/`

## توسعه محلی
فایل‌های این پوشه را ادیت کنید و با اسکریپت آپلود cPanel دوباره deploy کنید.
`config.php` روی سرور است و داخل گیت نیست.
