# فرایند آپدیت هم‌گپ (اجباری)

هر آپدیت فقط با این ترتیب:

## 1) چک آپشن‌های قبلی (Preflight)
- [ ] `version.php` نسخه فعلی را نشان می‌دهد
- [ ] وب‌هوک روی `dev.hdd-land.com/webhook.php` است
- [ ] ستون‌های لازم: `flow`, `ui_messages`
- [ ] سناریوهای قبلی هنوز OK هستند:
  - `/start` → پیام ۱ + پیام ۲ + دکمه دختر/پسر
  - سن با دکمه
  - استان (۳۱ استان) بعد شهر همان استان
  - شهر دیگر → درخواست متن
  - منوی قبلی بعد از `/start` پاک می‌شود

## 2) اعمال آپدیت
- فقط فایل‌های تغییرکرده را آپلود کن
- `Migrator::ensure` نباید داده را پاک کند (فقط ADD COLUMN امن)

## 3) چک خروجی (Verify)
- [ ] `version.php` = نسخه جدید
- [ ] `/start` واقعی در تلگرام
- [ ] `storage/error.log` بدون خطای جدید
- [ ] دکمه شهر دیگر و پاک‌سازی منو OK

اگر مرحله ۳ رد شد → rollback همان فایل‌ها، آپدیت را merge نکن.
