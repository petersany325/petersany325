# شهر بازی پَرَک — نمونه تست آنلاین

نمونه UI تعاملی برای منو و گزینه‌های **شهر بازی کودکان** و **آکادمی بازی**.

## اجرا

```bash
cd shahr-bazi-demo
python3 -m http.server 4173
```

سپس باز کنید: `http://127.0.0.1:4173`

## قابلیت‌های قابل تست

- منوی دسکتاپ / موبایل
- رزرو بازی آزاد (محاسبه قیمت)
- پکیج تولد + افزودنی‌ها
- فیلتر کلاس‌های آکادمی بر اساس سن
- انتخاب پلن عضویت
- رضایت‌نامه ورود
- فرم گروه‌ها و مدارس

داده‌ها ذخیره‌ نمی‌شوند؛ فقط برای پیش‌نمایش UX است.
