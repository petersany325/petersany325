  نصب سیستم مدیریت تعمیرگاه (HDD Land) — آموزش کامل فارسی
  نصب تحت وب، بدون Terminal / SSH / Composer (مناسب هاست اشتراکی)
═══════════════════════════════════════════════════════════════

این بسته شامل خود برنامه + پوشه vendor است.
روی هاست مشتری نیازی به اجرای composer نیست.


────────────────────────────────────────
۱) پیش‌نیازها
────────────────────────────────────────
• هاست با PHP 8.2 یا بالاتر (پیشنهادی: 8.3)
• افزونه‌های PHP: pdo, pdo_mysql, mbstring, openssl, tokenizer, xml, ctype, json, fileinfo, curl
• یک دیتابیس MySQL (یا امکان ساخت از طریق cPanel)
• دامنه یا ساب‌دامنه که به همین هاست اشاره کند (DNS درست)
• سریال لایسنس معتبر (از فروشنده / پنل لایسنس)


────────────────────────────────────────
۲) آپلود و Extract
────────────────────────────────────────
1. فایل zip را از لینک دانلود بگیرید.
2. در cPanel → File Manager بروید.
3. داخل پوشه‌ای که می‌خواهید نرم‌افزار نصب شود Extract کنید.
   مثال‌های رایج:
   • دامنه اصلی:   public_html/
   • ساب‌دامنه:    public_html/support/
   • ساب‌فولدر:    public_html/repair/

4. بعد از Extract باید پوشه hddland دیده شود، یا محتویات داخل همان مسیر باشد.
   اگر فقط یک پوشه به نام hddland ساخته شد، Document Root را روی همان بگذارید
   یا محتویات hddland را یک سطح بالاتر منتقل کنید.


────────────────────────────────────────
۳) تنظیم Document Root (خیلی مهم)
────────────────────────────────────────
این بسته طوری ساخته شده که Document Root می‌تواند روی «ریشه پروژه» باشد
(نه حتماً پوشه public).

حالت پیشنهادی (ساده‌ترین):
  Document Root = همان پوشه‌ای که install.php و artisan در آن است
  مثال ساب‌دامنه support:
    Document Root → /home/USER/public_html/support

حالت جایگزین:
  Document Root → .../public
  در این حالت آدرس نصب می‌شود: https://دامنه/install.php


────────────────────────────────────────
۴) DNS دامنه / ساب‌دامنه
────────────────────────────────────────
قبل از باز کردن سایت، دامنه باید به IP همین هاست برسد.

• اگر ساب‌دامنه در همان cPanel ساخته‌اید، معمولاً رکورد A خودش ساخته می‌شود.
• Nameserver دامنه در nic.ir باید مربوط به «همین سرور» باشد
  (مثلاً اگر هاست روی box408 است، NS هم باید box408 باشد نه سرور قدیمی).
• تست سریع: در مرورگر یا ابزار DNS باید IP دامنه = IP هاست باشد.

اگر دامنه resolve نشود، ویزارد نصب هم از بیرون باز نمی‌شود.


────────────────────────────────────────
۵) اجرای ویزارد نصب
────────────────────────────────────────
در مرورگر باز کنید:

  https://دامنه-شما/install.php

اگر Document Root روی public است:

  https://دامنه-شما/install.php
  (همان مسیر public)

مراحل ویزارد:

  مرحله ۱) پیش‌نیازها
    PHP و دسترسی نوشتن پوشه‌ها چک می‌شود. همه باید OK باشند.

  مرحله ۲) لایسنس
    • سریال لایسنس را وارد کنید
    • دامنه را دقیقاً همان دامنه‌ای بگذارید که لایسنس برایش صادر شده
      (مثال: support.example.ir بدون https و بدون اسلش انتهایی در فیلد دامنه — طبق فرم ویزارد)
    • سرور لایسنس معمولاً: https://support.hdd-land.ir

  مرحله ۳) دیتابیس
    دو روش:
    الف) خودکار با cPanel (پیشنهادی):
        یوزر و رمز ورود cPanel + نام دیتابیس/کاربر دلخواه
    ب) دستی:
        Host معمولاً 127.0.0.1 یا localhost
        Port: 3306
        نام دیتابیس، یوزر، رمز را از cPanel → MySQL Databases بردارید

  مرحله ۴) مشخصات سایت و مدیر
    • نام شرکت / تعمیرگاه
    • شعار، تلفن، آدرس (اختیاری)
    • لوگو (اختیاری)
    • آدرس سایت (APP URL) مثل: https://support.example.ir
    • نام، موبایل، ایمیل و رمز مدیر سیستم
    • اگر قبلاً نیمه‌کاره نصب کرده بودید، گزینه
      «پاک کردن جداول قبلی / نصب مجدد» را بزنید

  مرحله ۵) پایان
    پیام موفقیت + لینک ورود


────────────────────────────────────────
۶) بعد از نصب موفق
────────────────────────────────────────
• با ایمیل و رمزی که در ویزارد ساختید وارد شوید
  (در صفحه ورود فیلد «ایمیل یا موبایل» است)
• منوها و تعاریف اولیه خالی‌اند (داده دمو ساخته نمی‌شود)
• برای امنیت، بعد از ورود موفق می‌توانید این فایل‌ها را حذف/تغییرنام دهید:
    public/install.php
    install.php
    fix-install.php (اگر وجود دارد)
• در تنظیمات، برند شرکت / پیامک / درگاه و ... را تکمیل کنید


────────────────────────────────────────
۷) خطاهای رایج و راه حل
────────────────────────────────────────
۱) دامنه باز نمی‌شود / ERR_NAME_NOT_RESOLVED
   → DNS یا Nameserver اشتباه است. nic.ir و Zone Editor را با IP هاست چک کنید.

۲) خطای migrate: Table users doesn't exist
   → این بسته شامل migration پایه users است. اگر بسته قدیمی دارید آپدیت کنید
     یا گزینه «پاک کردن جداول قبلی» را در مرحله ۴ بزنید و دوباره نصب کنید.

۳) خطای users already exists / نیمه‌کاره قبلی
   → در مرحله ۴ گزینه پاک‌کردن جداول را فعال کنید، یا دیتابیس را خالی کنید.

۴) 500 بعد از نصب روی تنظیمات / داشبورد
   → کش را پاک کنید (اگر ابزار سیستم دارید) یا با پشتیبانی هماهنگ کنید.
     معمولاً با نصب تمیز از همین بسته برطرف می‌شود.

۵) لایسنس رد می‌شود
   → دامنه ویزارد باید دقیقاً همان دامنه قفل‌شده لایسنس باشد.
     www و بدون-www فرق دارند مگر لایسنس برای هر دو باشد.

۶) دسترسی پوشه / Permission
   → پوشه‌های storage و bootstrap/cache باید قابل نوشتن باشند ( معمولاً 755 یا 775).


────────────────────────────────────────
۸) ساخت ساب‌دامنه در cPanel (خلاصه)
────────────────────────────────────────
1. cPanel → Subdomains / Domains
2. Subdomain مثلاً: support
3. Document Root: public_html/support
4. منتظر DNS بمانید
5. zip را داخل همان Document Root Extract کنید
6. https://support.دامنه-شما/install.php


────────────────────────────────────────
۹) اطلاعات نسخه بسته
────────────────────────────────────────
• بسته نصب مشتری — کامل با vendor
• شامل migration پایه: users / cache / jobs
• نصب‌کننده تحت وب: install.php
• بدون نیاز به Composer روی هاست مشتری

در صورت مشکل نصب، این‌ها را برای پشتیبانی بفرستید:
• آدرس دامنه
• نسخه PHP هاست
• متن کامل خطا از صفحه ویزارد
• نام هاست/شرکت میزبانی
