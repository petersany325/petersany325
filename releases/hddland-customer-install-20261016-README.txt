بسته نصب کامل سیستم مدیریت تعمیرگاه
====================================

محتویات:
  hddland/           ← کل نرم‌افزار (با vendor)
  hddland/INSTALL-FA.txt  ← آموزش کامل فارسی نصب

مراحل خیلی کوتاه:
  1) فایل zip را در cPanel Extract کنید
  2) Document Root را روی پوشه hddland بگذارید
     (یا محتویات hddland را به مسیر ساب‌دامنه منتقل کنید)
  3) باز کنید: https://دامنه-شما/install.php
  4) مراحل ویزارد را با لایسنس و دیتابیس کامل کنید

جزئیات، DNS، خطاهای رایج و نکات امنیتی:
  → فایل hddland/INSTALL-FA.txt
