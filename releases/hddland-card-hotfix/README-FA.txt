چرا https://hdd-land.ir/card باز نمی‌شود؟
========================================
کارت ویزیت فقط داخل GitHub (PR #156) نوشته شده و روی سرور هنوز آپلود نشده.
الان لایو صفحه ۴۰۴ لاراول برمی‌گرداند: «صفحه پیدا نشد».

سی‌پنل و FTP این محیط برای آپلود مستقیم قبول نشدند.
باید این زیپ را خودتان در File Manager سی‌پنل روی هاست فروشگاه استخراج کنید.

روش سریع
--------
1) این زیپ را باز کنید.
2) محتویات پوشه drop-in-public/ را داخل Document Root سایت بگذارید
   (همان جایی که index.php لاراول / پوشه public است):
   - پوشه card/
   - فایل css/biz-card.css
   - پوشه images/card/
3) اگر ریشه پروژه (پوشه plugins) را هم می‌بینید، پوشه plugins/BizCard را هم کپی کنید.
4) یک‌بار باز کنید:
   https://hdd-land.ir/card/
   یا
   https://hdd-land.ir/public/card/

ذخیره در گوشی از /card/sarzamin-hard.vcf کار می‌کند.
باشگاه مشتری و پیامک بعد از کپی پلاگین BizCard فعال می‌شود.
