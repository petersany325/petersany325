# نصب روی هاست PHP

پکیج آماده آپلود برای هاست اشتراکی (cPanel / DirectAdmin و مشابه).

## پیش‌نیاز
- PHP 8.0 یا بالاتر
- افزونه `mbstring` (معمولاً فعال است)
- دسترسی به `mail()` برای ایمیل (اختیاری؛ بدون آن هم درخواست در فایل ذخیره می‌شود)

## نصب سریع (۳ قدم)

### ۱) آپلود
محتویات پوشهٔ `aryan-law-php` را داخل `public_html` (یا دامنهٔ سایت) آپلود کنید.

اگر فایل ZIP دارید:
1. ZIP را در `public_html` آپلود کنید
2. Extract کنید
3. مطمئن شوید `index.php` مستقیم داخل `public_html` باشد (نه داخل زیرپوشه اضافی)

### ۲) تنظیمات
فایل `config.php` را باز کنید و این‌ها را عوض کنید:

```php
'site_name'  => 'نام دفتر شما',
'phone'      => 'شماره تلفن',
'address'    => 'آدرس',
'email_to'   => 'ایمیل دریافت درخواست‌ها',
'email_from' => 'noreply@دامنه-شما.com',
```

### ۳) دسترسی نوشتن
پوشهٔ `storage/leads` باید قابل نوشتن باشد (معمولاً `755` یا `775`).

در File Manager اگر فرم ذخیره نشد، Permission همان پوشه را روی `775` بگذارید.

## تست
1. دامنه را باز کنید → باید صفحهٔ اصلی بیاید
2. فرم مشاوره را پر کنید و ارسال کنید
3. پیام موفقیت را ببینید
4. فایل JSON جدید داخل `storage/leads` ظاهر می‌شود

## ساختار فایل‌ها
```
aryan-law-php/
  index.php          ← صفحه اصلی
  contact.php        ← پردازش فرم
  config.php         ← تنظیمات (محافظت‌شده)
  .htaccess
  assets/            ← CSS، JS، تصاویر
  includes/          ← کدهای کمکی
  storage/leads/     ← ذخیره درخواست‌ها
```

## نکات هاست ایران
- اگر ایمیل نرسید، `send_mail` را `false` کنید؛ درخواست‌ها فقط در `storage/leads` می‌مانند
- برای دیدن درخواست‌ها از File Manager همان پوشه را باز کنید
- نیازی به دیتابیس و Composer نیست

## اجرای محلی (اختیاری)
```bash
cd aryan-law-php
php -S 127.0.0.1:8080
```
سپس `http://127.0.0.1:8080` را باز کنید.
