# هم‌گپ — نمونه طراحی منوی گرافیکی

فقط طراحی اولیه (هنوز به بات وصل نشده).

## محتویات
- `banners/` بنرهای منو (اصلی، هوشمند، کیف سکه، چت خصوصی)
- `preview/index.html` پیش‌نمایش شبیه تلگرام با دکمه‌ها

## مشاهده
فایل `preview/index.html` را در مرورگر باز کنید.

## مرحله بعد
پس از تأیید طرح:
1. فشرده‌سازی بنرها برای تلگرام
2. پیاده‌سازی داخل بات
3. اتصال پرداخت (زرین‌پال + کارت‌به‌کارت)
