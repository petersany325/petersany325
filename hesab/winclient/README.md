# حساب HDD — نرم‌افزار نصبی ویندوز (کامل)

نرم‌افزار **مجزا** تحت ویندوز با منوهای هم‌تراز سایت، لایسنس، SQL Server محلی، همگام‌سازی و به‌روزرسانی از GitHub.

## دانلود نصب‌کننده ۱٫۱٫۰

https://github.com/petersany325/petersany325/releases/tag/hesab-win-1.1.0

فایل: **`Hesab-HDD-Setup-1.1.0.exe`**

(اگر هنوز منتشر نشده، از Actions همان workflow آخرین Artifact را بگیرید.)

## سورس کامل

تمام سورس کلاینت ویندوز اینجاست:

```
hesab/winclient/
  HesabWin/          ← کد C# / WinForms
  installer/         ← Inno Setup
  build-installer.ps1
```

ریپو: https://github.com/petersany325/petersany325 (شاخه `cursor/hesab-accounting-app-aa3e`)

## ماژول‌های نسخه ۱٫۱

| منو | قابلیت |
|-----|--------|
| پرونده | داشبورد، همگام‌سازی، به‌روزرسانی، تنظیم SQL |
| اطلاعات پایه | کدینگ معین، طرف‌حساب، سال مالی |
| حسابداری | ثبت سند دوطرفه، فهرست اسناد، قطعی کردن |
| فروش | فاکتور + سند خودکار فروش/دریافتنی |
| گزارش‌ها | تراز آزمایشی |
| سیستم | لایسنس (همان قالب سایت)، تنظیمات |

خزانه / چک / ویزیتور: جداول SQL آماده‌اند؛ UI در نسخه‌های بعدی کامل می‌شود.

## لایسنس

همان الگوریتم وب (`HESAB-HDD-2026` + HMAC): از **سیستم → لایسنس** کلید را وارد کنید.  
اثر انگشت ویندوز در همان صفحه نمایش داده می‌شود.

## به‌روزرسانی (به‌جای ریموت دسکتاپ)

این محیط ابری به ویندوز شما دسترسی ریموت ندارد. مسیر به‌روزرسانی:

1. داخل برنامه: **پرونده → بررسی به‌روزرسانی**
2. یا نصب `Setup` جدید از Releases (روی نسخه قبلی نصب می‌شود)

## نصب

1. SQL Server 2022 محلی  
2. اجرای Setup  
3. جادوگر: `localhost` → ساخت دیتابیس → ورود  

## ساخت محلی Setup

```powershell
cd hesab\winclient
powershell -ExecutionPolicy Bypass -File .\build-installer.ps1
```
