# پکیج PHP سایت وکالت — آماده هاست

نسخهٔ قابل نصب روی هاست اشتراکی PHP (بدون لاراول، بدون Composer، بدون دیتابیس).

راهنمای کامل: [INSTALL.md](INSTALL.md)

## قابلیت‌ها
- همان طراحی RTL مؤسسه حقوقی آریان
- فرم مشاوره با CSRF و ضدبات ساده
- ذخیره درخواست در `storage/leads/*.json`
- ارسال ایمیل اختیاری با `mail()` هاست
- تنظیم نام/تلفن/ایمیل از `config.php`
