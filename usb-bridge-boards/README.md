# USB Bridge Boards

طراحی برد تبدیل ذخیره‌ساز به USB.

| پوشه | وضعیت | توضیح |
|------|--------|--------|
| [`jms578-sata-usb/`](jms578-sata-usb/) | فعال | استیک **SATA → USB 3.0** با JMicron JMS578 |
| `jms583-nvme-usb/` | رزرو | برای M.2 NVMe (هنوز طراحی نشده) |

برای ساخت و سفارش به JLCPCB/PCBWay فقط پوشه `jms578-sata-usb` را دنبال کنید.
